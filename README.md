## Description:
BlackJack_Web is a Chrome extension black jack game .

## File list:
* icon.png -> icon image for the extension
* index.css -> CSS styling file
* index.html -> UI page for the user
* index.js -> Backend Logic
* manifest.json -> Chrome extension config

## React
* Create react template
** For new app folder
> npm create vite@latest <NEW APP> . -- --template react
** For existing folder
> npm create vite@latest . -- --template react

* Install and run
> npm install
> npm run dev
